# SkillPanel/Maister — operator runtime extraction

Verified: 2026-10-04
Source: https://github.com/SkillPanel/maister
Authority: practitioner method / supporting evidence

## Extracted mechanisms

- task-local orchestrator state and durable artifacts for pause/resume;
- standards discovery from config, code patterns, documentation, PR/CI evidence with confidence/conflict handling;
- verification fan-out across completeness, tests, code review, pragmatic review, production readiness and reality assessment;
- operator dashboard and HTML companions as human observability;
- single work entrypoint routing into specialized workflows;
- lightweight quick paths for small tasks.

## PEOS delta

PEOS retains stronger constraints where the models differ:

- repository behavior / Git / executable evidence outrank orchestration state;
- observed convention is not an intended project rule;
- risk and decision materiality determine gates instead of a mandatory approval after every phase;
- executor and independent reviewer remain separate when the risk requires it;
- production learning and Definition of Value continue beyond implementation verification.

## Operationalized outputs

- Project Constitution Discovery;
- risk-derived execution profiles;
- operator front door;
- Verification Matrix.

No Maister source code is vendored. The implementation here is original and uses the repository as a practitioner reference.

## Evidence interpretation

The source is most useful as implementation evidence that these operator-runtime mechanisms can be expressed concretely in an agent-assisted SDLC: resumable task state, specialized verifier roles, confidence-oriented standards discovery and an operator-facing dashboard. It is not treated as evidence that Maister's exact phase count, mandatory approval frequency or one-session orchestrator topology is optimal for every project.

The adaptation therefore keeps the mechanism while changing the authority model. Project Constitution findings remain candidates until owner approval. Verification dimensions are selected from risk and claimed guarantees rather than always running every reviewer. Dashboard state is reconstructed from canonical runtime state and evidence instead of becoming a second writable registry. Low-risk work receives a fast path, but consequential effects still escalate to the stronger evidence profile regardless of diff size.

## Disconfirmation conditions

These patterns should be revised if executed evaluations show that constitution discovery systematically fossilizes legacy conventions, verification fan-out creates duplicated findings without improving defect detection, or operator artifacts cost more context than they preserve. Production and workflow telemetry should be used to test those hypotheses rather than promoting practitioner mechanisms permanently after one source review.
