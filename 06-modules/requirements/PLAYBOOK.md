# Requirements playbook

Requirements are a traceability bridge, not a transcription layer.

Canonical chain:
`EVIDENCE → NEED/OUTCOME → REQUIREMENT → SCENARIO → ACCEPTANCE CRITERION → DESIGN/ARCH DECISION → TEST → PRODUCTION SIGNAL`

Use quality-attribute scenarios for important NFRs: source/stimulus/environment/artifact/response/response measure. Do not write vague NFRs such as "fast", "secure" or "scalable" without a response measure or explicit uncertainty.
