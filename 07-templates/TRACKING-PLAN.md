## Naming rules
Use stable domain/product verbs, not UI labels, unless UI interaction is explicitly the measured construct.

## Data quality
Expected volume/denominator, deduplication, ordering/timestamp assumptions, late events, schema validation, missing-data monitoring and ownership.
