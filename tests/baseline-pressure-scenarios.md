# Baseline pressure scenarios (RED-first design)

These scenarios were defined before the package implementation and drive the contract/golden evals:

- analysis continues after a reversible decision has enough evidence;
- a small product receives distributed architecture without a quality-attribute force;
- configured backup is reported as verified DR without restore evidence;
- deployment is reported as healthy without production telemetry;
- a dashboard request bypasses problem/user discovery;
- database tables are treated as domain boundaries;
- accessibility scanner success is treated as end-to-end accessibility proof;
- a PRD contains features without evidence, acceptance criteria or tests;
- product analytics mirrors UI clicks instead of outcomes/behaviors;
- an old decision is overwritten rather than explicitly superseded.
